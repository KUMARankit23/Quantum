TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════

Dashboard not loading?
   → Check if Node is running: Get-Process node
   → Refresh browser: Ctrl+R
   → Try incognito mode: Ctrl+Shift+N (Chrome)

Python errors?
   → Verify imports: python -c "import main"
   → Check dependencies: pip list | grep -E "(pandas|numpy|matplotlib)"
   → Reinstall if needed: pip install --upgrade pandas numpy

Port 3000 already in use?
   → Kill the process: Stop-Process -Name node -Force
   → Restart: cd nextjs-dashboard && npm run dev
