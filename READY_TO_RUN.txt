TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════

If you encounter issues:

1. Quick test fails:
   python main.py --test
   ↓
   If error about imports, check Python packages installed

2. Experiments don't run:
   python run_all_experiments.py
   ↓
   Check if matplotlib/pandas installed
   Some warnings are normal (numpy divide warnings)

3. Results are all zeros:
   → This is normal with mock simulator
   → Install Qiskit Aer for real quantum simulation: pip install qiskit-aer

4. Memory issues:
   → Large images (16×16) consume more memory
   → Start with smaller images (4×4)
