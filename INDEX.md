### Source Code Modules

#### `src/preprocessing/` (4 modules)
**Purpose**: Image loading and preprocessing
- `dataset.py` - Generate test images
- `image_loader.py` - Load and process images
- `normalization.py` - Normalize pixel values
- `__init__.py` - Package initialization

#### `src/quantum/` (4 modules)
**Purpose**: Quantum computing operations
- `encoding.py` - Amplitude encoding implementation
- `circuit_builder.py` - Build quantum circuits
- `executor.py` - Execute circuits on simulators
- `noise_models.py` - Noise simulation
- `__init__.py` - Package initialization

#### `src/classical/` (1 module)
**Purpose**: Classical baseline methods
- `baseline.py` - 5 classical processing methods

#### `src/reconstruction/` (2 modules)
**Purpose**: Convert quantum measurements back to images
- `measurement_processor.py` - Process measurement results
- `image_reconstructor.py` - Reconstruct images
- `__init__.py` - Package initialization

#### `src/evaluation/` (2 modules)
**Purpose**: Calculate quality metrics
- `metrics.py` - Image quality metrics
- `quantum_metrics.py` - Quantum-specific metrics
- `__init__.py` - Package initialization

#### `src/experiments/` (3 modules)
**Purpose**: Orchestrate controlled experiments
- `experiment_config.py` - Configuration management
- `experiment_runner.py` - Run single experiment
- `batch_runner.py` - Run all 6 experiments
- `__init__.py` - Package initialization

#### `src/visualization/` (5 modules)
**Purpose**: Generate plots, analysis, dashboard, report
- `plot_generator.py` - 7 automatic plot types
- `comparison_plots.py` - Image comparison visualizations
- `results_analyzer.py` - Automatic finding extraction
- `dashboard.py` - HTML dashboard generator (NEW)
- `report_generator.py` - Research report generator (NEW)
- `__init__.py` - Package initialization

## KEY CONCEPTS QUICK REFERENCE

### Amplitude Encoding
Formula: |ψ⟩ = (1/√Z) Σ √(I_i) |i⟩  
Meaning: Pixel intensity → quantum amplitude

### Circuit Types
- **BASIC**: Minimal gates
- **MEDIUM**: 3 layers with entanglement
- **DEEP**: 5 layers, complex circuit

### Noise Models
- **Bitflip**: X error
- **Phaseflip**: Z error
- **Depolarizing**: General noise
- **Readout**: Measurement error
- **None**: Ideal simulator

### Experiments
- **A**: Resolution (image size)
- **B**: Shot count (measurements)
- **C**: Noise (error rates)
- **D**: Circuit depth (complexity)
- **E**: Image type (patterns)
- **F**: Quantum vs Classical (comparison)
