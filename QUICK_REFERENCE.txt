🧪 EXPERIMENTAL DESIGN (6 Experiments)
───────────────────────────────────────────────────────────────────────────────

Exp A: Resolution Scaling
  Change: Image size (2×2 → 4×4 → 8×8 → 16×16)
  Measure: Qubits, gates, time, quality

Exp B: Shot Count Impact
  Change: Measurements (100 → 500 → 1000 → 5000)
  Measure: Quality, variance, time

Exp C: Noise Effects
  Change: Noise type (none, bitflip, phaseflip, depolarizing, readout)
  Measure: Quality degradation

Exp D: Circuit Complexity
  Change: Depth (low → medium → high)
  Measure: Time, fidelity, noise sensitivity

Exp E: Intensity Representation
  Change: Encoding (binary, grayscale, normalized)
  Measure: Precision, fidelity

Exp F: Quantum vs Classical
  Compare: Quantum vs Gaussian blur
  Measure: Time, quality, memory


📊 EVALUATION METRICS (8 metrics)
───────────────────────────────────────────────────────────────────────────────

Image Quality:
  MSE              Mean Squared Error (lower is better)
  PSNR             Peak Signal-to-Noise Ratio (higher is better)
  SSIM             Structural Similarity (higher is better)

Additional:
  MAE              Mean Absolute Error
  Correlation      Pixel correlation
  Fidelity         Quantum state similarity

Circuit:
  Qubits, Gates, Depth, 2-qubit gate count

Performance:
  Execution time, memory usage, scaling


📈 QUANTUM REPRESENTATION
───────────────────────────────────────────────────────────────────────────────

Amplitude Encoding:
  Formula: |ψ⟩ = (1/√Z) Σ √(I_i) |i⟩
  
  Where:
    I_i = pixel intensity
    Z = normalization factor
    |i⟩ = computational basis state

Qubit Requirements:
  2×2 image    → 2 qubits
  4×4 image    → 4 qubits
  8×8 image    → 6 qubits
  16×16 image  → 8 qubits
